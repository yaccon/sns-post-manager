# SNS投稿管理（Ver.3.8）

iPhoneのブラウザでX・Threadsへの投稿を準備・確認する、半自動の投稿管理Webアプリです。投稿の最終確認と送信は利用者が手動で行います。

**アプリ**：https://yaccon.github.io/sns-post-manager/

## 基本的な使い方

1. 「今日の投稿」で日時・投稿先・本文を確認する
2. 「本文コピー」を押し、「Xを開く」または「Threadsを開く」で移動する
3. 投稿先の画面で内容を確認し、手動で投稿する
4. アプリに戻り、「投稿済みにする」を押す
5. 定期的に「データのバックアップ」→「バックアップを保存」でJSONを保存する

過去投稿・参考投稿・週14/42本生成の補助などもありますが、毎日の運用では上の5操作を基本にしてください。スレッドは本文を1本ずつコピーする形式です。

## 大切な注意点

- **データは基本的に、このアプリを開いたブラウザの保存領域（localStorage）に保存します。** iPhoneの別ブラウザ・別端末へ自動同期されません。
- ブラウザデータの削除、機種変更、プライベートブラウズの利用状況等によりデータが消える可能性があります。バックアップファイルは別の安全な場所にも保管してください。
- バックアップJSONには投稿本文、過去履歴、参考投稿、投稿形式設定などが含まれます。**公開GitHubリポジトリへ個人のバックアップJSONをアップロードしないでください。**
- 「バックアップを保存」を押しただけで保存が完了したとは限りません。iPhoneの「ファイル」でJSONを確認してください。
- XやThreadsへの自動送信、画面を閉じた状態での確実なプッシュ通知、Googleカレンダーとの双方向同期、端末間同期は提供していません。
- 過去投稿ZIPの取り込みでは、必要時に外部CDNからZIP展開ライブラリを取得します。ZIPが読み込めない場合は公式ZIPを解凍し、投稿データ（例：`tweets.js`）を選んでください。DMなどのファイルは取り込まないでください。
- X Premium長文の投稿可否は、利用者自身のXアカウント契約・機能に依存します。

## 復元方法

「データのバックアップ」→「バックアップを復元」→ JSONを選択 → 内容を確認して承認します。

Ver.3.8の保守修正では、投稿IDのない古いバックアップを繰り返し復元した際の二重登録を防ぐ処理を追加しました。同じIDの投稿は端末側の現在の内容を優先し、上書きしません。
