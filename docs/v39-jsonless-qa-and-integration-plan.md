# Ver.3.9: 投稿管理アプリのJSONを意識しない取り込み

## ゴール
iPhoneで毎週42件（3アカウント×14件）を生成・登録し、投稿当日は上部の「今日の投稿」をコピーするだけで済ませる。

### Ver.3.9 テスト機能（追加API料金0円）
- 「生成指示をコピー」→ ChatGPTで文章を生成 → ChatGPT回答の「コピー」 → アプリへ戻る → **「コピーした投稿を読み込んで確認」**。
- ユーザーにはJSON入力欄を普段見せない。クリップボードをボタン押下時のみ読み取り、**既存の安全なインポート検査**（14/28/42件の枠・X/Threads・文字数・形式・過去履歴類似判定）へ送る。
- 通常版で使っているローカルストレージ（投稿・履歴・参考投稿・形式設定）は**すべてそのまま**。生成結果の確認だけでは保存しない。類似候補・重複を確認し、最後に登録操作を選んだ後だけ保存する。
- iOSでクリップボード権限が許可されなかった場合は「手動で入力する」を自動表示し、既に入力した内容も消さない。
- AI生成自体はまだChatGPTの画面で行う。**「完全にアプリだけでAIに生成させる」機能ではない**と明示する。
- テスト版 qa-jsonless-v39.html は4つのキーを通常版と完全分離。架空の14件を確認できるテストボタンあり。

## 完全アプリ内AI生成の調査（実装前に要検証）
- OpenAIの **Sign in with ChatGPT** は、対応するオープンソース／参加アプリで、ユーザーが許可したChatGPTプラン枠を利用できる機能を提供している（PlusがあってもChatGPT会話履歴・メモリをアプリが読み取る権限ではない）。
- 公式資料： https://developers.openai.com/siwc/quickstart 、https://developers.openai.com/siwc/token-sharing-open-source 、https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites 。
- ただし当アプリはiPhone用GitHub Pages静的サイト。公式オープンソース実装例はローカルランタイムとループバックOAuth、保護された認証情報保存が前提。**いまの公開HTMLに秘密トークンを埋め込んだり、localStorageへOAuthアクセストークンを保存する実装はしない**。
- 商用提供・遠隔ホスト版では認証/利用許可や申請要件をさらに調査する。無料利用を保証せず、プラン限度とモデルの対応を確認してから、別の企画として試作する。
- 追加料金ゼロ・ユーザーがAPIキーを登録しない・プライバシー保護が優先条件。

## QA確認
1. QAページを開き、最上部「今日の投稿」を確認。
2. 生成指示をコピーし、ChatGPTで14本（X通常投稿推奨）を生成して返答の「コピー」を押す。
3. QAへ戻って「コピーした投稿を読み込んで確認」を押す。コピー内容が正しければ14件の確認が表示される。
4. クリップボードが許可されない場合は手動入力から貼り付け、同じ確認画面に進める。
5. サンプル14本ボタンも利用可能。確認後に登録し、投稿一覧で状態を確認。QAデータは通常版には反映されない。
6. 問題なければ通常版Ver.3.8の最新バックアップを確保して、ユーザーの明示承認後に統合する。
