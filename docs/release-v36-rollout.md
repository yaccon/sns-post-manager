## 問題が起きた場合の復旧

- まず本番の追加投稿・編集を止める。症状と件数を記録する。
- GitHubのマージコミットをrevertするか、旧版の`index.html` / JSの内容を戻す。**端末内のlocalStorageのデータは初期化しない**。
- 必要な場合は、マージ前に保存したJSONをアプリ内の「バックアップを復元」で追加する。既存データのID一致重複は除外される。復元前に既存件数と追加見込みを確認する。
- アプリを削除、サイトデータの消去、iPhoneの履歴削除は行わない。

## 無料配布版にする前の別作業

**このVer.3.6はユーザー自身が使う運用版の統合候補。一般向け無料配布版としては未完成。**

- **最優先**：カイ/後輩くん/漫画恋愛という固定アカウント設定と専用プロンプトを一般ユーザーが自由に編集できる方式にする。公開版と自分用の企画設定は分離する。
- 初回セットアップ：使い方、投稿先の選択、スマホからのコピー/投稿済み切替、JSONバックアップの流れを3ステップ程度で説明。
- プライバシー/データ：投稿内容は各ユーザーのブラウザ内localStorageに保存。サーバー同期はしない。ブラウザデータ消去・機種変更で失われ得るためJSONバックアップが必要。外部のZIP取り込みライブラリ取得など外部依存も説明。
- 仕様の明示：ChatGPTの生成指示をコピーして自分で送信する方式。X/Threadsへの送信は手動。**予約時刻にSNSへ自動投稿したり、アプリを閉じたままiPhoneへ通知したりはできない**。
- **予定時刻のお知らせの実機テストが未完了**。以前のiPhone検証で通知が来なかった報告がある。ページを開いたときのみ利用可能な画面内の案内であり、時刻ちょうどの通知を保証しない。正式公開前に検証し、必要なら案内表示または仕様を調整する。
- Android Chrome/PC Chrome/Safari/Edgeの基本操作とファイル保存・復元を検証。
- データ量が増えた場合の保存容量の警告、失敗時の復旧導線を検証。
- 配布用のリンク、操作説明、問い合わせ先、更新方法を用意。一般向けの呼称とバージョンを決定。
- LINE登録誘導に使う場合は、提供条件、個人情報の取り扱い、配布後のサポート範囲を明記。
